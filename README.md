# 📚 Smart StudyFocus

An AI-assisted Android application designed to help students stay focused during study sessions by reducing distractions, tracking focus time, and providing study analytics. The application encourages productive study habits using a Pomodoro-based timer, distraction monitoring, and productivity tracking.

---

## 📱 Features

- ⏱️ Pomodoro Focus Timer
  - 30 Minutes
  - 60 Minutes
  - 3 Hours

- 📊 Study Analytics
  - Track completed focus sessions
  - Daily and weekly study reports
  - Visual charts for productivity
  - Track study and distraction data

- 🚫 Distraction Monitoring
  - Detects selected distracting apps
  - Displays a reminder notification when distraction apps are opened during an active focus session
  - Helps users return to studying
  - Records distraction activity for productivity analysis

- 🔐 User Authentication
  - Login Screen
  - Registration Screen
  - User-specific access

- 🔍 Search Feature
  - Search for study-related topics
  - Quickly access study information
  - Maintains recent search history
  - View previously searched topics

- 💾 Local Data Storage
  - Stores study session data
  - Stores productivity and distraction records
  - Uses SQLite for local data management

- 🎨 Modern User Interface
  - Clean and student-friendly design
  - Material Design Components
  - Easy navigation between application features

---

## 📝 Project Description

Smart StudyFocus is an Android application developed to help students improve their concentration, manage study time effectively, and reduce digital distractions during study sessions.

The application features a Pomodoro-based focus timer with customizable study durations, distraction monitoring, productivity analytics, search functionality, and a modern user-friendly interface.

During an active study session, the application monitors selected distracting applications and encourages users to return to their studies through reminder notifications.

The application also records study sessions, tracks productivity and distraction activity, and presents detailed analytics to help users understand and improve their study habits over time.

The Search Feature allows students to search for study-related topics and keeps a record of recent searches, making it easier to revisit previously searched information.

Built using **Java, XML, Android Studio, SQLite, Material Design Components, and Android Usage Stats API**, Smart StudyFocus provides an efficient and practical solution for students who want to develop better time management and maintain consistent focus.

The project also provides a foundation for future AI-powered features such as personalized study recommendations, intelligent productivity analysis, smart learning assistance, and adaptive study planning, making it a scalable solution for modern educational needs.
